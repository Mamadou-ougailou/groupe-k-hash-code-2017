Instance Studio

Générateur d'instances — Hash Code 2017, « Streaming videos »

Dimensions
Tailles des vidéos

Un coefficient de variation proche de 0 rend l'exposant sur la taille sans effet dans un glouton par ratio.

Topologie

Le mode géographique place endpoints et caches sur un anneau : les caches proches se partagent des endpoints, ce qui crée du recouvrement réaliste.

Latences

Étalement à 0 : tous les caches d'un endpoint ont la même latence, donc retirer une vidéo ne coûte rien et le local search se retrouve sur un plateau. À 1 : les écarts sont maximaux et la solution est rigide.

Requêtes

Le taux de duplication contrôle la part de lignes qui répètent un couple (vidéo, endpoint) déjà présent — le motif qui fait tomber les parseurs qui écrasent au lieu d'accumuler.

Envoie un fichier .in : le serveur vérifie le format et toutes les bornes de l'énoncé.
